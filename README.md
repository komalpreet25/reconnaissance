# Reconnaissance

A learning repository documenting my understanding and practical experience with reconnaissance techniques during my cybersecurity training.

This repository contains notes, concepts, commands, tool usage, practical exercises, and observations related to information gathering and reconnaissance.

## 📌 About This Repository

During my cybersecurity training, I started learning about reconnaissance and its importance in cybersecurity and penetration testing.

Reconnaissance is the process of collecting information about a target to understand its domain, network infrastructure, technologies, services, and potential attack surface.

I created this repository to organize my learning, document the techniques and tools I explore, and maintain a technical reference that I can revisit as I continue developing my cybersecurity skills.

## 🎯 Learning Objectives

- Understand the fundamentals of reconnaissance.
- Learn the difference between passive and active reconnaissance.
- Explore OSINT techniques and information gathering.
- Understand domain and DNS enumeration.
- Learn network and web application reconnaissance.
- Explore commonly used reconnaissance tools.
- Perform practical exercises in authorized lab environments.
- Understand how to analyze and document reconnaissance findings.
- Develop a better understanding of security assessment methodologies.
